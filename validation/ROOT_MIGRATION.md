The earlier nested `susieSlide/` package did not match the requested repository
layout. It has been removed. The root of
`C:/Document/Serieux/Travail/Package/git/susieR`, on branch `susie_slide`, is now
the **susieSlide 0.2.0 package itself**.

## Request-to-implementation checks

| Requested behavior | Corrected implementation |
|---|---|
| Work in the named repository and branch | Root `DESCRIPTION` contains `Package: susieSlide`; branch is `susie_slide`. Only one DESCRIPTION remains in the repository. |
| Call the slider through the package's main function | `susieSlide::susie()` is defined in `R/slider.R` and returns class `c("susie_slide","susie")`. |
| Replace the single-effect fitting step with the slider | `R/slider_engine.R` supplies slider likelihoods, posterior moments, residual updates, expected squared residuals, KL and conditional ELBO calculations to the included IBSS engine. |
| Keep the Gaussian coefficient prior | Beta is integrated under `N(0,V_l)` using the SuSiE internal coefficient scale. V can be fixed or learned. |
| Estimate delta in [-1,1] | The compiled `src/slider.cpp` solver compares endpoints and all stationary points of the conditional marginal likelihood. |
| Force delta=0 for sparse genotype categories | `min_obs=5` fixes delta at zero if any retained genotype count is below five, including an absent category. Boundary and precedence tests pass. |
| Adapt to internal rescaling | The internal predictor is `[(x-mean(x))+delta*(I(x==1)-mean(I(x==1)))]/sd(x)`, with the same original additive SD for both terms. Output delta remains dimensionless in original genotype coordinates. |
| Similar SuSiE output, plus deltas | Standard posterior, evidence, fitted-value and CS fields remain; `delta` aligns with alpha, and `delta_cs` has one row per SNP per reported CS. |
| Use slider evidence | `lbf_variable` contains Gaussian evidence evaluated at fitted delta; it is not taken from the additive regression. These remain plug-in scores, not evidence integrated over a delta prior. |
| Correct predictions and CS purity | Predictions use additive and heterozygote coefficients. CS purity uses component-specific transformed genotypes. |
| Build/document from the existing RStudio project | The exact `devtools::document(roclets=c("rd","collate","namespace"))` command succeeds from the repository root and reports `susieSlide`. |

## Root-package changes

The original additive engine is included in this fork. Its individual-data
entry point is explicitly named `susie_additive()`. Legacy RSS, sufficient-
statistic, automatic and trend-filter interfaces remain additive; their
internal calls and tests use that explicit entry point. Slider fitting has
**no runtime dependency on susieR**. susieR is suggested for independent
comparison scripts only.

Native registration is generated by cpp11 for `susieSlide`, including the
slider solver. R documentation and NAMESPACE are generated from source,
including registration of the inherited internal S3 methods required by the
installed roxygen2 version. The missing `decor` development dependency was
installed. The existing RStudio project can be used from the same folder;
the project filename does not determine the package namespace.

The full inherited suite exposed a Windows issue in iteration plots: the
system filesystem utility `convert.exe` was being mistaken for ImageMagick.
Detection now checks for the image converter and otherwise keeps the PDF.
Three old RSS test assertions expected residual variance to be disabled under
mismatch correction. A direct probe of the unchanged installed susieR showed
that it permits the joint estimation and emits a hint. Those stale assertions
were updated to its existing behavior; the model calculation was not changed.
Missing imports, a few S3 signatures, two help arguments, portable BLAS
linking, and console output were also corrected as required by package checks.

The current built vignette introduces the slider. Inherited additive tutorials
are preserved under `validation/upstream-vignettes/`; their function calls
explicitly target the additive interface. Original authorship and licensing
are retained. The original README and site configuration are archived here.

- `devtools::document(roclets=c("rd","collate","namespace"))`: successful.
- Standard `devtools::test()` suite: **4,424 passed assertions**, zero failures,
  errors or warnings; four skipped tests. One skip requires ImageMagick; three
  skips are inherited (two disabled CI cases and a simulation with no CS).
- `R CMD build` from the requested repository: successful, including the
  slider vignette.
- `R CMD check --no-manual --no-tests susieSlide_0.2.0.tar.gz`:
  **Status: OK**, no warnings or notes. Unit tests were run separately as
  reported above. Examples and vignette rebuilding were included in this check.
- Installed the root-built package into the user's R 4.6 library.
- Fresh `Rscript --vanilla` session: package version 0.2.0; slider fitting did
  not load the susieR namespace.
- Refit all six saved first-replicate scenarios: additive, recessive, partially
  recessive, dominant, partially dominant and mixed. All converged. Alpha, mu,
  mu2, delta, lbf_variable, V, sigma2, fitted values, PIPs and ELBO were
  **identical** to the earlier validated implementation (maximum difference
  zero). Prediction and summary/CS-delta checks passed.

See `root-devtools.log`, `root-package-check.log`, `root-build.log`,
`root-install.log`, `root-scenario-regression.log`, and
`root-scenario-regression.csv`. Reproduce the last audit with
`Rscript --vanilla validation/audit-root.R` after installing the root package.

The earlier numerical comparison, null diagnostics and timings are retained
in `REPORT.md`. The timing experiments were not repeated merely for this
layout migration. The statistical limitation remains: optimized deltas can
inflate null PIPs, and genome-wide calibration is not established.
